# Credits

These skills are adapted from Matt Pocock's skills, <https://github.com/mattpocock/skills> (commit `d81f3a1`, 2026-09-29):

| Skill here        | Upstream                                               | Changes                                                                   |
| ----------------- | ------------------------------------------------------ | ------------------------------------------------------------------------- |
| `grilling`        | `skills/productivity/grilling`                         | Asks in the user's language                                               |
| `domain-modeling` | `skills/engineering/domain-modeling`                   | Single context, LePatron vocabulary, ADR status and epic link             |
| `grill-with-docs` | `skills/engineering/grill-with-docs`                   | Model-invoked, wired into the new feature workflow, always ends in an ADR |
| `to-prd`          | `skills/engineering/to-spec` (formerly `to-prd`)       | Publishes the PRD as a `⛰ Epic` GitHub issue                              |
| `to-issues`       | `skills/engineering/to-tickets` (formerly `to-issues`) | Ticket 01 is the ADR + tests PR, tickets are GitHub sub-issues            |
| `tdd`             | `skills/engineering/tdd`                               | Jest 27 and `tests/` conventions, the skipped-tests first PR              |

Upstream, `to-prd` was renamed `to-spec` and `to-issues` was merged into `to-tickets`; the names are kept here because they are the ones the team uses.
